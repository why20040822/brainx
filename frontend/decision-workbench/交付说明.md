# B-tex 职位决策台前端原型

这是可独立运行的前端演示包，不含 BrainX 后端、飞书授权、数据库或任何真实业务数据。

## 运行条件

- Node.js 22.13 或更高版本
- npm 10 或更高版本

## 启动

在解压后的项目目录运行：

```bash
npm install
npm run dev
```

然后在浏览器打开终端显示的本地地址（通常是 `http://localhost:3000`）。

## 验证

```bash
npm test
```

该命令会执行生产构建和前端静态测试。

## 说明

- 职位、同步、授权、承接、结果、回放和通知均为本地 Mock 状态。
- 操作状态通过浏览器 `localStorage` 保留；清除浏览器站点数据即可还原演示初始状态。
- 接入真实后端时，从 `app/decision-demo.ts` 替换为接口适配层即可；前端不应重新计算排序或将 `UNKNOWN` 当作 0。
