# BrainX 职位决策工作台｜原包内优化版

本目录来自用户提供的 `btex-decision-workbench-frontend-2026-08-12.zip` 副本；原始压缩包没有被修改。

## 本次做了什么

- 保留原包的工作台骨架：左侧导航、中央任务区、右侧上下文抽屉；
- 保留同步、关注、接单、结果记录、决策轨迹、回放、通知和本地状态；
- “我的承接”改为左侧常驻工作区；点击职位后在右侧直接处理承接与结果；
- 删除中间页面底端重复的承接模块；左栏收起时保留图标和数量角标；
- 移动端通过顶部入口打开全屏承接抽屉，不把承接列表放回底端；
- 首页收敛为投放、增长负责人、市场负责人三个方向，每方向展示 Top 3；
- 显示推进、探索、个人适配、最终四个后端分数；
- 区分“驾驶舱上下文”和“职位市场”来源；
- Nooklab 等 Offer 覆盖 HC 但入职未知的项目进入核验池，不占 Top 3；
- 判断策略保留三层手工软权重 60 / 25 / 15，并明确硬规则不可覆盖；
- 删除了错误的 A/B/C 独立概念页，避免维护两套产品。

## 数据边界

当前仍是前端演示快照，数据来自 2026-08-11 已核验的职位决策 rerun。页面不会连接或修改 TTC、飞书、驾驶舱。接入后端时，排序和事实判断必须由 API 返回，前端不得自行计算最终名次。
